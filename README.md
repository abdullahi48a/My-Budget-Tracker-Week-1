
# My Budget Tracker

## Description
My Budget Tracker is a simple personal budget and expense tracking website built using HTML and CSS.

## Features
- Main heading and website description.
- Add Expense section.
- Expense name input field.
- Amount input field.
- Category input field.
- Your Expenses section.

## Technologies Used
- HTML5
- CSS3

## Project Files
- index.html - Contains the HTML structure.
- style.css - Contains the CSS styling.
